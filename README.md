# 生境 · 豁然开朗（Bio Spatial Learning）

> **把每一个冰冷的生命科学知识点，做成一场微观尺度具身漫游的 3D 时空微剧场。**  
> 突破传统生物学“看静态解剖图、死背名词回路”的痛点，让学习者化身红细胞、氧分子或神经冲动，在微观器官拓扑中经历速度、尺度与因果交换。

## 核心设计理念

1. **具身视角（Embodied Perspective）**：
   * 不做旁观者的“人体模型展览”，而是让学生成为生理过程中的运动主体（如：成为一颗红细胞、成为一个氧分子）。
2. **尺度连续跃迁（Powers of Ten）**：
   * 宏观器官（胸腔/心脏） $\to$ 组织管网（血管/支气管） $\to$ 细胞（红细胞/肺泡上皮） $\to$ 分子（血红蛋白/氧气）。
3. **生理因果交互（Causal Exploration）**：
   * 氧浓度差如何驱动扩散？心率变化如何改变血流流速与壁面剪切力？用动态滑块让学生自己“破坏平衡”并“观察涌现”。
4. **感官闭环叙事（Sensory Storytelling）**：
   * 视听高度协同：程序化合成的心跳搏动（Web Audio API Sub-bass）、血管壁节律蠕动、暗紫静脉血与鲜红动脉血的即时染色。

## 核心剧场选题规划

| 课题 | 核心视角 | 顿悟瞬间（The Epiphany） | 状态 |
| :--- | :--- | :--- | :--- |
| **《一滴血的旅行》** | 成为红细胞（RBC） | 经历心脏泵血冲刺，在肺泡与全身毛细血管中完成氧合与释氧闭环 | **已上线 (GitHub Pages)** |
| **《一口气的旅程》** | 成为氧分子（$O_2$） | 从鼻腔宏观气流冲刷，经肺泡扩散嵌入血红蛋白，最终在线粒体完成细胞呼吸（首尾“吸气-呼气”闭环） | 规划中 |
| **《一次免疫战争》** | 成为巨噬细胞/中性粒细胞 | 皮肤破损，病原体入侵，趋化因子引导穿出血管，吞噬与呈递抗原的微观战场 | 规划中 |
| **《神经冲动的极速狂飙》** | 成为动作电位（Action Potential） | 沿轴突飞驰，$Na^+/K^+$ 离子通道如多米诺骨牌般开闭，在突触间隙化作神经递质雨 | 规划中 |

## 本作技术架构

* **3D 真实宏微双视界并置**：
  * **宏观**：左侧保留未来全息圆柱舱定位雷达，中央新增 500px 巨幅真实立体骨骼透视人体图与医学引线标注（肺动脉干、肺泡毛细血管、主动脉弓、左心室、降主动脉、下腔静脉）。
  * **微观**：右侧与背景展现 3D 血管管腔与第一人称/特写双凹圆盘红细胞（基于 Evans-Fung 截面方程）。
* **纯程序化 Web Audio 心搏音效引擎**：
  * 零外部音频文件依赖，数学合成第一心音 S1（55Hz 咚）与第二心音 S2（80Hz 哒），配合血流粉红噪声滤波。
* **真实双循环物理动线**：
  * 严格遵循人体生理学闭环：右心室 ➔ 肺动脉 ➔ 肺泡毛细血管（变鲜红）➔ 肺静脉 ➔ 左心室 ➔ 主动脉弓 ➔ 组织释氧（变暗紫）➔ 腔静脉 ➔ 右心房。
